# AI Usage Log

## AI Assistance

AI assistance was used to support implementation, debugging, testing, and documentation across the three project workflows.

- Knowledge Brain: Assistance with API structure, article retrieval, database integration, and response citations.
- Inbox Agent: Assistance with email classification, reply drafting, and storing human review feedback.
- Meeting to Scope: Assistance with structured scope generation, task estimates, and follow-up scope comparison.

## Human Validation

Generated code and outputs were tested manually. Scope comparison tests covered identical scopes, estimate-only changes, empty task lists, genuine additions and removals, and selected wording variations.

## Limitations

AI-generated outputs can be inaccurate. Evaluation results reflect only the tests actually executed. Further testing is needed for retrieval quality, email drafting quality, and end-to-end reliability.
